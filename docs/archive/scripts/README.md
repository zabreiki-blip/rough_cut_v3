# Архив одноразовых скриптов

Скрипты 2026-10-06 для ремонта конкретных ревизий проекта BRIK (зашитые под
него правки нормализации, TTS и синхрона Louella). Они вынесены из `scripts/`,
чтобы там остались только эксплуатационные команды, и не входят в Docker-образ,
CI и тесты. Не запускайте их на других проектах без ревью.

- `repair_brik_revision.py` — общие помощники (`backup`, `read_json`) и ремонт
  ревизии; импортируется остальными скриптами из соседнего каталога.
- `finish_brik_tts.py` — досинтез реплик BRIK.
- `finish_brik_normalization.py` — применение проверенных правок нормализации.
- `repair_brik_louella_sync.py` — исправление синхрона Louella.

Контекст — в [`BRIK_AUDIT_2026-10-06.md`](../audits/BRIK_AUDIT_2026-10-06.md).
Скрипты импортируют друг друга по имени модуля, поэтому запускайте их из этого
каталога (`python docs/archive/scripts/<имя>.py`).
