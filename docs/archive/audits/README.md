# Архив аудитов

Документы в этом каталоге фиксируют состояние проекта на момент проверки.
Выводы могли быть закрыты последующими изменениями. Для текущей работы см.
[`../../README.md`](../../README.md) и
[`../../TECH_DEBT.md`](../../TECH_DEBT.md).
Ручные проверки Premiere — в [чеклисте пилота](../../E2E_PILOT_CHECKLIST.md).
