# Архив документации

Здесь хранятся документы, описывающие состояние проекта или внешнего рынка на
конкретную дату. Их выводы нельзя считать текущим планом без повторной проверки.

- [Аудиты](audits/README.md) — результаты проверок и снимки проектов.
- [Планы](plans/README.md) — прежние дорожные карты и планы исправлений.
- [Исследования](research/README.md) — датированные материалы о рынке.
- [Одноразовые скрипты](scripts/README.md) — BRIK-скрипты ремонта проекта,
  вынесенные из `scripts/`; не входят в Docker-образ и CI.

Актуальные инструкции перечислены в [индексе документации](../README.md).
