# Иностранные синхроны: результат реализации

Дата: 16.11.2026. Код в рабочей папке rough_cut_v3; коммиты и публикация не выполнялись.

## Что работает

- Просмотровка + существующий DOCX из TRANSCRIBE_v2 + русский сценарий. Нового экспорта и изменений TRANSCRIBE_v2 не требуется. Word загружается в карточку соответствующего источника.
- Поиск по русскому переводу, подсказкам спикера, источника и времени. Кандидаты требуют проверки границ. Отдельный смысловой поиск включается явно; модели передаются только русские тексты цитаты и кандидатов, максимум 24 кандидата и 8 вызовов по 45 секунд. При лимитах или сбое остаются обычные результаты и видимый статус.
- Связь с исходником и репликой документа; относительные и камерные таймкоды, смещение просмотровки, исходные отметки Word. Повторный импорт сохраняет ручные границы и требует проверки затронутых назначений. Подтверждение после изменения документа доступно и без устаревшей привязки.
- Отдельная русская озвучка синхрона: TTS для черновика, живой переводчик для мастера, диапазоны общей записи. Оба варианта сохраняются. Есть «Только исходник», задержка, уровни и совместный предпросмотр.
- Длинный перевод увеличивает монтажное место, сдвигает следующие блоки и оставляет чёрный промежуток после исходного видео. Источник и звук не растягиваются; повторная сборка пересчитывает позиции заново.
- Финальный XML Stage 3 содержит отдельную дорожку перевода и приглушение оригинала. Устаревший экспорт Stage 2 направляет к Stage 3 вместо потери перевода.

Порядок действий — в [руководстве пользователя](../../USER_GUIDE.md#синхроны-и-сборка). Если программа была запущена до изменения кода, перезапустите её и обновите страницу.

## Проверки

- Полный Python-прогон окончательного кода: **3366 passed, 35 subtests passed**, 124,45 с.
- Поведенческие проверки нового интерфейса и **65** существующих проверок интерфейса прошли.
- Mypy: **96 файлов**, без ошибок. Ruff, контракт/генератор API и проверка пробелов git прошли.
- Сквозной тест: DOCX → поиск → подтверждение → запись → сборка → XML. Внешний синтез и смысловой помощник подменены; документы, WAV, хранилища и построение таймлайна настоящие временные.
- Дополнительно проверено чтение двух реальных старых Word-экспортов с неболдированным русским переводом: 176 и 264 реплики. Это проверка структуры, а не точности диапазонов реального монтажа.
- Финальная проверка кода выявила и закрыла ошибки смещения, привязки альтернатив, повторного подтверждения и плеера. Часть дополнительных тестов написана после исправлений; полный RED/GREEN для каждого теста не заявляется.
