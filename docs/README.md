# Документация rough_cut_v3

Этот файл — точка входа в рабочую документацию. Текущие задачи ведутся в
`TECH_DEBT.md`; датированные аудиты фиксируют состояние кода на указанном
коммите и не являются сами по себе текущим списком ошибок.

## Начало работы

- [`../README.md`](../README.md) — быстрый старт, настройка, API, тесты и Docker.
- [`STAGE1_GUIDE.md`](STAGE1_GUIDE.md) — работа со сценарием, нормализация и TTS.
- [`../cep/README.md`](../cep/README.md) — установка и использование CEP-панели
  Premiere Pro.
- [`E2E_PILOT_CHECKLIST.md`](E2E_PILOT_CHECKLIST.md) — ручной сквозной пилот в
  Premiere Pro.

## Разработка и сопровождение

- [`DEPENDENCY_POLICY.md`](DEPENDENCY_POLICY.md) — политика зависимостей,
  качества и поддерживаемых платформ.
- [`GENERAL_AUDIT_2026-10-21.md`](GENERAL_AUDIT_2026-10-21.md) — аудит на
  `b8fbc6c` с отметкой о последующих исправлениях на `5042ab8`.
- [`RECOGNITION_MATCHING_AUDIT_2026-10-21.md`](RECOGNITION_MATCHING_AUDIT_2026-10-21.md)
  — состояние ASR и сопоставления, включая оставшиеся ограничения.
- [`AUDIT_PLAN_2026-10-16.md`](AUDIT_PLAN_2026-10-16.md) — сводный план
  исправлений по аудиту 2026-10-16 (находки B1–B18); исторический план,
  текущие задачи перенесены в `TECH_DEBT.md`.
- [`TECH_DEBT.md`](TECH_DEBT.md) — реестр технического долга: что сознательно
  не сделано и не проверено.

## Архив

- [`archive/README.md`](archive/README.md) — более ранние исследования,
