# Документация rough_cut_v3

Начните с раздела для своей задачи. Открытые задачи и непроверенные ограничения
ведутся в [TECH_DEBT.md](TECH_DEBT.md). Датированные аудиты и планы описывают
состояние на момент написания и сами по себе не являются текущим списком ошибок.

  синхроны, редакции и XML.
- [Первый проект](FIRST_PROJECT_CHECKLIST.md) — демо и ручная проверка результата.

- [Stage 1 подробно](STAGE1_GUIDE.md) — сценарий, нормализация и TTS.
