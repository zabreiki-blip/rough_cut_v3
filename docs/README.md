# Документация rough_cut_v3

Этот файл — единая точка входа в документацию проекта. Инструкции и рабочие
документы перечислены отдельно от архивных аудитов, чтобы исторические выводы
не воспринимались как текущий backlog.

## Начало работы

- [`../README.md`](../README.md) — быстрый старт, настройка, API, тесты и Docker.
- [`STAGE1_GUIDE.md`](STAGE1_GUIDE.md) — работа со сценарием, нормализация и TTS.
- [`../cep/README.md`](../cep/README.md) — установка и использование CEP-панели
  Premiere Pro.
- [`E2E_PILOT_CHECKLIST.md`](E2E_PILOT_CHECKLIST.md) — ручной сквозной пилот в
  Premiere Pro.

## Разработка и сопровождение

- [`../DEVELOPMENT_PLAN.md`](../DEVELOPMENT_PLAN.md) — roadmap и активные
  направления разработки.
- [`FRISKE_001_FINAL_REVIEW_FIX_PLAN_2026-09-08.md`](FRISKE_001_FINAL_REVIEW_FIX_PLAN_2026-09-08.md)

- [`DEPENDENCY_POLICY.md`](DEPENDENCY_POLICY.md) — политика зависимостей,

## Продуктовый контекст

- [`COMPETITOR_COMPARISON.md`](COMPETITOR_COMPARISON.md) — сравнение с

## Архив

  снимки состояния проекта. Они сохраняются как история решений и не являются
  текущим списком задач.

Внутренние планы инструментов в `.kilo/` не относятся к пользовательской
документации проекта.
