# rough_cut_v3

Из сценария, закадра и просмотровок приложение собирает черновой таймлайн
и XML для Premiere Pro. Основной путь — браузер: сценарий → проверка блоков
→ озвучка → синхроны → таймлайн → XML.

## Быстрый старт

Нужны Python 3.11 и ffmpeg/ffprobe. На macOS их можно установить командой
`brew install python@3.11 ffmpeg`; для старых `.doc` дополнительно нужен
`catdoc` (`brew install catdoc`). Запускайте команды из корня репозитория:

```bash
PYTHON_BIN=python3.11 ./scripts/setup-local
./scripts/run-local
```

Укажите Python явно: системный `python3` может быть старее поддерживаемого.
Setup создаёт окружение, устанавливает зависимости и локальный ASR, создаёт
`.env` с новым `ROUGH_CUT_API_TOKEN`, папки данных и запускает диагностику.
Нативный Apple Silicon автоматически использует MLX и `.venv-macos-arm64`
(Python 3.11/3.12); CPU, включая Rosetta, — faster-whisper и `.venv` (Python 3.11).
Профиль и путь можно задать явно — [настройки](docs/CONFIGURATION.md#профиль-локальной-установки).

Оставьте процесс run открытым и перейдите на [http://127.0.0.1:8000/](http://127.0.0.1:8000/).
В окне Basic Auth введите **любое имя пользователя**, а в поле пароля —
**значение `ROUGH_CUT_API_TOKEN`** из локального `.env`. Это сгенерированный
пароль приложения, не облачный API-ключ. Для диагностики: `./scripts/doctor`.

## Первый проект

Для демо откройте второй терминал в корне репозитория:

```bash
./scripts/create-demo
```

Откройте напечатанный URL. Команда создаёт новый проект с готовыми файлами
и не запускает обработку. Пройдите [чеклист первого проекта](docs/FIRST_PROJECT_CHECKLIST.md):
выберите сценарий → проверьте и подтвердите блоки → «Озвучка» / «Готовая запись»
→ сопоставьте и подтвердите закадр → распознайте и проверьте синхрон локально
→ «Собрать таймлайн» → «Скачать XML для Premiere».

Готовые записи включены в демо; платные ключи не нужны. Whisper-модель
скачивается при первом распознавании: нужны сеть и место на диске, время
зависит от сети, модели и компьютера. Выбор `small` для демо описан в
[чеклисте](docs/FIRST_PROJECT_CHECKLIST.md). Модель не входит в демо.
На нативном macOS можно дополнительно выбрать синтез `macos` через `say`.
Режим CLI `--dry-run` создаёт WAV-заглушки без речи. Фактический импорт текущего
демо в Premiere ещё не проверен: после скачивания XML проверьте импорт вручную.

Для своих материалов создайте проект на стартовой странице. Приложение создаст:

| Папка внутри `projects/<project>/` | Что положить |
| --- | --- |
| `ЗАГРУЗИТЬ/Сценарии/` | `.docx`, `.doc`, `.txt`, `.md` |
| `ЗАГРУЗИТЬ/Просмотровки/` | Видео и отдельные `.wav` / `.mp3` |
| `ЗАГРУЗИТЬ/Закадр/` | Готовая запись диктора `.wav` / `.mp3` |

Разметка короткого сценария, полный список расширений, два варианта озвучки
(«Создать озвучку» / готовая запись), «Проверить аудиофайлы», синхроны и
редакции описаны в [руководстве пользователя](docs/USER_GUIDE.md).
Первичный разбор создаёт рабочий сценарий; последующие исходники загружайте
через «Редакции» → «Загрузить новую редакцию».

## Другие способы запуска и справочники

Docker — явная альтернатива локальной установке: `./scripts/bootstrap-docker`.
Он использует CPU; на Apple Silicon Metal доступен только нативному приложению.
