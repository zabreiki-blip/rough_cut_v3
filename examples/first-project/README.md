# Первый демо-проект

Из корня репозитория после установки по основному README:

```bash
./scripts/create-demo
./scripts/run-local
```

Откройте URL, напечатанный первой командой. Каждый запуск создаёт новый проект
`demo_<suffix>`; существующие проекты и их правки сохраняются. Команда только
копирует файлы, не запускает сервер, модели, сеть или платные сервисы.

Выберите `scenario.txt`, проверьте порядок ЗК → СНХ → ЗК и подтвердите сценарий.
На вкладке «Озвучка» используйте **«Готовая запись»** и `narrator.wav`: в нём
прочитаны только два закадровых блока с паузой между ними. Сопоставьте запись
локально, прослушайте границы, подтвердите оба блока и примените к редакции.
Для синхрона используйте `review.wav`, локальный ASR и реплику «Сегодня мы
открываем новый маршрут вдоль реки.». Проверьте границы на слух и соберите XML.
Полный путь с проверками и выбором модели: [чеклист](../../docs/FIRST_PROJECT_CHECKLIST.md).

`expected.json` хранит только ожидаемое содержание, порядок типов, имя спикера
и цитату. Он не содержит таймингов, подтверждений или готового результата
распознавания и не копируется в рабочие результаты проекта.

Сценарий оригинальный, персонаж Анна Миронова вымышленный. WAV созданы для
этого демо локальным macOS `say` (голос Milena, 145 слов/мин), затем преобразованы
в mono PCM16 WAV, 16000 Гц. Голос в просмотровке синтетический, это не запись
реального интервью. Файлы уже включены: macOS и синтез для прохождения демо
не нужны. Native macOS TTS — дополнительный вариант озвучки, см. чеклист.
